# PayPal preview

This hosted demo includes only a simulated PayPal design preview. It does not connect to PayPal, accept credentials, capture funds, create orders or change stock through the preview. Approval, cancellation and error buttons only change the preview message. Existing TEST orders remain separate. No payment account or credentials are configured. The PayPal Sandbox adapter is not published in this update.

The private local preparation also contains a separate, unvalidated Sandbox adapter. That is not a production integration and needs authorized test accounts before end-to-end validation. Real sales need a separate approved implementation with merchant ownership, prices, shipping, taxes, legal terms, verified webhooks and order/stock reconciliation.
